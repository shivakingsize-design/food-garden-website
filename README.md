# Food Garden — Demo Website

A responsive restaurant website concept built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a browser. Internet access is required for Google Fonts and the illustrative Unsplash photographs.

## Before presenting to the restaurant
- This is an independent demo concept, not an official Food Garden website.
- Confirm the restaurant's preferred business name, phone number, exact address, opening hours and current menu.
- Confirm dish availability and prices directly with the restaurant.
- Replace illustrative stock photographs with approved restaurant/food photographs.
- Update the online-ordering link to the restaurant's exact listing if the owner confirms it.
- Obtain permission before publishing as the restaurant's official website.

## Deployment
Upload the files while preserving their names and folder structure to GitHub Pages, Netlify or another static hosting provider.
